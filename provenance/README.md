# Provenance records

One record per asset, grouped by character (`cat/`, `dinosaur/`, `robot/`).
Each record states where the asset came from, how it was made, and its
commercial-use status.

No records exist yet. The record schema and the first records are defined in
**KCK-02**. Until a record says otherwise, no asset here may be assumed to be
cleared for any use. Unknown means `pending`, never inferred.
